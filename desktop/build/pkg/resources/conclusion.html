Phone Farm is installed

Open Phone Farm from your Applications folder (or Launchpad) to finish setup.

On first launch choose Set up a new host on this machine if this Mac will control the phones, or Connect to an existing Phone Farm host if you are joining a host that is already running.

A host Mac stays awake while it runs phones and opens Phone Farm by itself when the Mac starts. If anything needs attention, the setup screen shows a Fix it button; if something still does not work, choose Help → Copy Diagnostics in Phone Farm and send the result to whoever supports you.
