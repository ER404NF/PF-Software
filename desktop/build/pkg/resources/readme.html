Before you start

Computers that only connect to an existing Phone Farm host

Nothing else is required. Open Phone Farm and choose Connect to an existing Phone Farm host.

The Mac that will control the iPhones (the host)

Phone Farm automates the phones through Apple's own developer tools, which stay on your Mac. You do not need to use Terminal: when Phone Farm opens, its setup screen checks each item below and shows a Fix it button for anything it can do for you.

  • macOS 12 or later, Apple silicon.
  • Xcode from the App Store. You do not need to open it; if it still needs finishing, Phone Farm does it and macOS asks for your Mac password once.
  • The USB tools libimobiledevice and libusbmuxd. Phone Farm installs them for you when this Mac has Homebrew (free, from brew.sh); if it does not, the setup screen says so.
  • An Apple Developer account signed in to Xcode. Phone Farm finds your Team ID by itself; if there is more than one, it asks you to choose once.
  • On each iPhone: turn on Developer Mode, tap Trust when connecting it to the Mac, and keep it unlocked the first time.

WebDriverAgent is included in the app; you do not need to download it.
